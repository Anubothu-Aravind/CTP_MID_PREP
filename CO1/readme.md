## Section Summaries

### Section A: Computational Thinking
Decomposition, Abstraction & Pattern Recognition applied to real-world software system scenarios.

### Section B: Algorithm Design & Complexity
Analyzing searching and sorting paradigms, runtime growth rates, and space-time trade-offs.

### Section C: Divide and Conquer
Algorithmic paradigms for splitting problems, solving sub-problems recursively, and combining outputs.

### Section D: Dynamic Programming
Optimizing overlapping subproblems and memoization strategies.

### Section E: Greedy Algorithms
Making locally optimal choices to achieve globally optimal solutions.

### Section F: Backtracking
Systematic state-space tree traversal and constraint satisfaction problem solving.
